A run ends at the first row the plugin marks invalid (valid ≠ 1 or validity_state ≠ in_domain; without those columns, the first row with ukc_min ≤ 0). That row and everything after it are not shown, because the plugin switches its canal physics off there. One value per second is shown, the latest at or before each second. The status label comes from how the run ended (critical within 60 s of the end, caution within 180 s); it is not an AI prediction. These rules match raseen_data/gazebo_import.py.
